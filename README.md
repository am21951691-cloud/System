# 🏥 نظام إدارة حالات المجمع الطبي (Medical Complex System)

نظام متكامل وخفيف الوزن لإدارة حالات المرضى واللجان الطبية والروشتات وقرارات الصرف في المجمعات والمراكز الطبية الخيرية، مبني بأحدث معايير **Next.js 15** و **SQLite عبر Prisma ORM**.

---

## 🌟 مميزات النظام الأساسية

1. **فصل ملف المريض عن الزيارة (`Patient ≠ Visit`):**
   - لكل مريض ملف دائم موحد برقم تسلسلي (`PAT-XXXXXX`).
   - إمكانية إضافة زيارات متعددة وتاريخ مرضي كامل تحت نفس الملف دون تكرار التسجيل.

2. **تسجيل متكامل في شاشة واحدة:**
   - شاشة إضافة مريض جديد تتيح تسجيل البيانات الشخصية، تفاصيل الكشف الطبي، والروشتة بقائمة الأدوية دفعة واحدة مع إمكانية الإرسال المباشر للجنة الطبية.

3. **دورة عمل محكمة ومتسلسلة (Workflow):**
   - **الاستقبال/الطبيب:** إدخال بيانات الكشف وتوصيف الروشتة والأدوية.
   - **اللجنة الطبية:** مراجعة التاريخ المرضي للمريض وإبداء الرأي المستقل (موافق على الصرف / غير موافق / يحتاج معلومات إضافية).
   - **قرار الصرف النهائي:** اعتماد نوع الصرف (كفالة وصدقة / بمقابل مالي / رفض) مع تحديد مدة وجدول الصرف (مثال: علبة شهرياً لمدة 6 شهور).

4. **لوحة متابعة ديناميكية تفاعلية (`/dashboard`):**
   - إحصائيات حية للحالات المعلقة والمعتمدة.
   - بحث فوري برقم الملف أو الاسم أو الهاتف.
   - تبويبات تصفية دقيقة، وقسم مخصص لاستعراض سجل المرضى المسجلين.

5. **تقارير A4 احترافية وطباعة PDF:**
   - تقرير زيارة معتمد يشمل تفاصيل الكشف، الروشتة، آراء اللجنة، والقرار النهائي مع أماكن الأختام والتوقيعات.
   - تقرير أرشيفي كامل بجميع زيارات المريض التاريخية بضغطة زر واحدة.

6. **سجل رقابي غير قابل للتعديل (Audit Log):**
   - توثيق آلي لكل إجراء في النظام مع اسم المستخدم وتاريخ ووقت العملية بالثانية.

7. **حسابات موحدة وتصميم متجاوب:**
   - حسابات خاصة بدون تسجيل مفتوح لضمان أمان النظام الداخلي.
   - واجهة متجاوبة بالكامل (`RTL`) تدعم الهواتف الذكية والأجهزة اللوحية والحواسيب المكتبية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Framework:** Next.js 15 (App Router)
* **Frontend:** React 19, Vanilla CSS (Modern Dark Theme, RTL, Noto Sans Arabic)
* **ORM & Database:** Prisma ORM مع SQLite
* **Authentication:** Stateless JWT Sessions عبر مكتبة `jose` و `bcryptjs`
* **Language:** TypeScript

## 🚀 التشغيل والإعداد المحلي (Getting Started)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد المتغيرات البيئية:
انسخ ملف الإعدادات التجريبي:
```bash
cp .env.example .env
```

### 3. إنشاء قاعدة البيانات وبدء السجل:
```bash
npx prisma db push
npx prisma db seed
```

### 4. تشغيل خادم التطوير:
```bash
npm run dev
```

افتح المتصفح على:
* محلياً: [http://localhost:3000](http://localhost:3000)
* عبر الشبكة المحلية (WiFi/LAN): `http://<IP_ADDRESS>:3000`

## ☁️ النشر والتشغيل على Cloudflare (Cloudflare Deployment)

النظام مهيأ بالكامل للعمل عبر شبكة **Cloudflare** مع ملف الإعداد `wrangler.toml` المرفق. يمكنك اختيار الطريقة الأنسب لطبيعة عمل المجمع الطبي:

### 🌟 الخيار الأول: النشر عبر Cloudflare Pages (استضافة سحابية كاملة)

1. **ربط المستودع:**
   - من لوحة تحكم Cloudflare، انتقل إلى **Workers & Pages** ← **Create application** ← **Pages** ← **Connect to Git**.
   - اختر مستودع النظام: `https://github.com/am21951691-cloud/System`.

2. **إعدادات البناء (Build Settings):**
   - **Framework preset:** `Next.js`
   - **Build command:** `npx @opennextjs/cloudflare` أو `npm run build`
   - **Build output directory:** `.worker-next` (أو `.next`)
   - **Compatibility date:** `2024-09-23`
   - **Compatibility flags:** `nodejs_compat`

3. **المتغيرات البيئية (Environment Variables):**
   - في إعدادات المشروع بـ Cloudflare Pages:
     - `NODE_ENV`: `production`
     - `JWT_SECRET`: مفتاح تشفير عشوائي قوي للجلسات (مثال: `openssl rand -hex 32`).
     - `DATABASE_URL`: رابط قاعدة بيانات سحابية متوافقة مع البيئة السحابية بدون خادم (مثل Neon PostgreSQL أو Supabase أو Turso أو Cloudflare D1).

---

### 🛡️ الخيار الثاني (الأمثل للمجمعات الطبية والمستشفيات): Cloudflare Tunnel (`cloudflared`)

هذا الخيار هو **الأعلى أماناً والأكثر انتشاراً في المنشآت الطبية**، حيث يتيح تشغيل النظام وقاعدة البيانات المحلية على جهاز السيرفر بالمجمع الطبي بأعلى سرعة وأقل تكلفة، مع حمايته برابط عالمي آمن من Cloudflare دون فتح أي منافذ بالراوتر (Port Forwarding):

1. **تشغيل الخادم محلياً أو عبر PM2 / Docker:**
   ```bash
   npm run build
   npm run start
   ```

2. **تثبيت وربط Cloudflare Tunnel:**
   ```bash
   # تثبيت أداة cloudflared
   winget install Cloudflare.cloudflared

   # تشغيل نفق فوري محمي برابط Cloudflare مجاني
   cloudflared tunnel --url http://localhost:3000
   ```

3. **ربطه بنطاقك المخصص (Custom Domain):**
   - يمكنك ربطه بنطاق مثل `clinic.yourdomain.com` بنقرة واحدة من لوحة **Cloudflare Zero Trust** ← **Access** ← **Tunnels**.
   - تحصل تلقائياً على حماية DDoS، شهادة SSL عالمية مجانية، وسرعة استجابة فائقة عبر شبكة Cloudflare العالمية مع بقاء سجلات المرضى آمنة على السيرفر الداخلي.
