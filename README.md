# 🏥 نظام إدارة حالات المجمع الطبي (Medical Complex System)

نظام متكامل، سريع، وعالي الأمان لإدارة حالات المرضى، اللجان الطبية، الروشتات، وقرارات صرف الأدوية في المجمعات والمراكز الطبية الخيرية، مبني بأحدث معايير **Next.js 15 (App Router)**، **React 19**، و **Prisma ORM مع SQLite**.

> 📖 **للاطلاع على التقرير الفني الشامل وتفاصيل ما تم إنجازه وخارطة الطريق:**  
> يرجى مراجعة [وثيقة المشروع الشاملة (PROJECT_DOCUMENTATION.md)](PROJECT_DOCUMENTATION.md).

---

## 🌟 مميزات النظام الأساسية

1. **فصل ملف المريض عن الزيارة (`Patient ≠ Visit`):**
   - لكل مريض ملف دائم موحد برقم تسلسلي منظم (`PAT-XXXXXX`).
   - إمكانية إضافة زيارات متعددة وتاريخ مرضي كامل تحت نفس الملف دون تكرار التسجيل.

2. **تسجيل متكامل في شاشة واحدة:**
   - شاشة إضافة مريض جديد تتيح تسجيل البيانات الشخصية، تفاصيل الكشف الطبي، والروشتة بقائمة الأدوية دفعة واحدة مع إمكانية الإرسال المباشر للجنة الطبية.

3. **دورة عمل محكمة ومتسلسلة (Clinical Workflow):**
   - **الاستقبال / العضو:** تسجيل بيانات المريض والكشف وقائمة الأدوية الموصوفة.
   - **اللجنة الطبية (`committee_review`):** مراجعة التاريخ المرضي للمريض وقرارات الصرف السابقة، وتسجيل الرأي المستقل (موافق على الصرف / غير موافق / يحتاج معلومات إضافية).
   - **القرار النهائي للطبيب (`doctor_review`):** حصر صلاحية القرار النهائي بالأطباء والمديرين فقط، وتحديد نوع الصرف (كفالة وصدقة مجانية / بمقابل مالي / رفض) مع تحديد مدة وجدول الصرف (مثال: علبة شهرياً لمدة 6 شهور) مع إمكانية تعديل القرار عند الحاجة.

4. **لوحة متابعة ديناميكية تفاعلية (`/dashboard`):**
   - إحصائيات حية للحالات المعلقة والمعتمدة.
   - بحث فوري وسريع برقم الملف، الاسم، أو رقم الهاتف.
   - تبويبات تصفية دقيقة، وقسم مخصص لاستعراض سجل المرضى المسجلين بالكامل.

5. **إدارة متقدمة للمستخدمين والصلاحيات (`/admin/users`):**
   - واجهة مدمجة للمدير لإضافة حسابات المستخدمين الجديدة وتعيين أدوارهم (`طبيب معتمد`، `عضو لجنة / استقبال`، `مدير نظام`).
   - تفعيل وتعطيل الحسابات فورياً بنقرة زر مع حماية الحساب الحالي للمدير من التعطيل العرضي.

6. **تقارير رسمية جاهزة للطباعة والتصدير كـ PDF:**
   - تقرير زيارة معتمد يشمل تفاصيل الكشف، الروشتة، آراء اللجنة، والقرار النهائي مع أماكن الأختام والتوقيعات الرسمية.
   - تقرير أرشيفي كامل بجميع زيارات المريض التاريخية بضغطة زر واحدة.

7. **سجل رقابي غير قابل للتعديل (Audit Log):**
   - توثيق آلي لكل إجراء في النظام (إنشاء حسابات، تعديل قرارات، تسجيل مرضى) مع اسم المستخدم وتاريخ ووقت العملية بالثانية.

## 🛡️ معايير الأمان والحماية السيبرانية (Cybersecurity Hardening)

تم تأمين النظام وفق أفضل ممارسات الأمن السيبراني للتطبيقات الصحية:

* 🔒 **التحكم الصارم في الوصول (RBAC & BFLA Defense):**
  حماية كافة الـ Server Actions ومسارات الخادم، والتحقق الصارم من صلاحيات المستخدم (مدير / طبيب / عضو) قبل تنفيذ أي إجراء.
* ⏱️ **الحماية ضد هجمات القوة الغاشمة (Rate Limiting):**
  نظام حماية داخلي في الذاكرة آمن من تسريب الموارد، يحدد المحاولات بـ 10 محاولات لكل عنوان IP و 5 محاولات لكل تركيبة (IP + اسم مستخدم) خلال 15 دقيقة.
* 🛡️ **منع هجمات التوقيت واستكشاف الحسابات (Timing Attack Mitigation):**
  تشغيل مقارنة Bcrypt بديلة ثابتة (`DUMMY_HASH`) في حال إدخال اسم مستخدم غير موجود لتوحيد زمن الاستجابة ومنع تخمين الحسابات.
* 🍪 **تأمين الجلسات (Stateless JWT Sessions):**
  تشفير HMAC-SHA256 عبر WebCrypto (`jose`) وتخزين الرموز في ملفات تعريف ارتباط ذات خواص: `httpOnly`, `sameSite: lax`, `secure`.
* 📜 **ترويسات أمان متقدمة وسياسة أمان المحتوى (CSP):**
  تطبيق `Content-Security-Policy`، `Strict-Transport-Security (HSTS)`، `X-Frame-Options: SAMEORIGIN`، `X-Content-Type-Options: nosniff`، و`Permissions-Policy`.
* 🧼 **تنقية المدخلات ومنع حقن البيانات (Input Sanitization & SQLi Defense):**
  تنقية النصوص وإزالة الـ Null Bytes، مع استخدام استعلامات Prisma المعلمية بالكامل.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Framework:** Next.js 15.5 (App Router)
* **Frontend:** React 19, Vanilla CSS (Modern Theme, RTL, Touch-Friendly, Noto Sans Arabic)
* **ORM & Database:** Prisma ORM 5.22 مع SQLite
* **Authentication:** Stateless JWT Sessions عبر مكتبة `jose` و `bcryptjs`
* **Language:** TypeScript

## 🚀 التشغيل والإعداد المحلي (Getting Started)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد المتغيرات البيئية:
انسخ ملف الإعدادات التجريبي:
```bash
cp .env.example .env
```

### 3. إنشاء قاعدة البيانات وبدء السجل:
```bash
npx prisma db push
npx prisma db seed
```

### 4. تشغيل خادم التطوير:
```bash
npm run dev
```

افتح المتصفح على:
* محلياً: [http://localhost:3000](http://localhost:3000)
* عبر الشبكة المحلية (WiFi/LAN): `http://<IP_ADDRESS>:3000`

## ☁️ النشر والتشغيل على Cloudflare (Cloudflare Deployment)

### 🛡️ الخيار الأمثل والآمن (Cloudflare Tunnel):
تشغيل النظام محلياً أو على سيرفر المنشأة، ثم حمايته بنفق مشفر مجاني من Cloudflare:
```bash
# تثبيت cloudflared
winget install Cloudflare.cloudflared

# تشغيل نفق آمن فوري برابط عالمي
cloudflared tunnel --url http://localhost:3000
```
يوفر هذا الخيار حماية كاملة من هجمات DDoS مع شهادة SSL مجانية وحفظ بيانات المرضى محلياً داخل المنشأة بأقصى درجات الخصوصية والأمان.
